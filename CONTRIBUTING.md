# Contributing

Follow the [Devfile contributing guide](https://github.com/devfile/api/blob/main/CONTRIBUTING.md) when contributing to this repository.
See the [README](README.md#how-to-run-integration-tests-on-a-local-machine) for instructions on running the integration tests.

## AI-Assisted Contributions

Contributions created in whole or in part with generative AI tools must comply
with the project's [AI Governance](https://github.com/devfile/api/blob/main/GOVERNANCE.md#ai-governance), including its
review, licensing, and attribution requirements.
